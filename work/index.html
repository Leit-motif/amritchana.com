How it's built

Noesis, from the inside

Work arrives from chat, from a voice app on my phone and from a scheduler. The orchestrator plans it and hands pieces to sub-agents and coding agents. Anything they would put in front of another person stops at the gate first.

Orchestrator and sub-agents
The main agent plans and delegates. Sub-agents each take one task, run in parallel and report back; coding work goes to Claude Code, Codex or Cursor over ACP. Six agents are configured, including Venture, which runs the pipeline for my own business.
Scheduled workers
56 scheduled jobs: a 6am digest, memory checks, nightly backup and self-repair, a nightly retro, business follow-ups at 12:30 and 17:30. Some are plain scripts with no model; the rest name the model that fits the job.
Memory over MCP
openclaw-mcp is an MCP server I wrote. It gives each approved client bounded queries over the memory wiki and active memory, limited to that client's own tool profile. A Hindsight extension adds memory search with a keyword fallback.
Model routing
Each job and agent names its model, with fallbacks: Claude Opus or Sonnet for most agent work, GPT for scheduled briefs, Grok as an independent reviewer in the gate. quota-guard asks before a run on a provider with 5% or less of its usage window left.
Gateway extensions
Plugins I wrote for the OpenClaw Gateway. blocker-reversal forces one more pass when an agent gives up while it still has routes of its own. machine-pool sends browser work to whichever paired machine has headroom. ops-heal turns failed cron runs into incidents; skill-usage logs which skills get read so unused ones can be cut.
The public-preflight gate
Anything in my name that leaves the system, an email, a post, a write to a public repo, is held until two things happen: I approve the exact text, and an adversarial review passes it. The agents can draft all day; they can't publish.
Evals and hill-climbing
A gate, prompt or skill gets scored before a change ships. The gate has its own case set, scored below. Judges are checked against blind second labellers on held-out sets. Improvement runs change one thing per round and judge it on held-out cases.
